## Opdracht
<br>

In de vorige oefening tekende je met een functie een sprite. Nu gebruik je die functie opnieuw, maar deze keer teken je twee sprites na elkaar met een verschillend aantal beentjes.

### Gegeven

Je gebruikt de `turtle`-module.

De gebruiker geeft twee getallen in:
- het aantal beentjes voor de eerste sprite
- het aantal beentjes voor de tweede sprite

### Wat moet je doen?

+ maak een functie met de naam `teken_sprite`
+ geef de functie één parameter voor het aantal beentjes
+ laat de functie een sprite tekenen
+ laat de functie een boodschap teruggeven als de tekening klaar is
+ vraag aan de gebruiker het aantal beentjes voor de eerste sprite
+ vraag aan de gebruiker het aantal beentjes voor de tweede sprite
+ voer de functie uit
+ toon de boodschap in de console
+ verplaats de turtle naar rechts
+ voer de functie opnieuw uit
+ toon de boodschap opnieuw in de console

### Verwachte uitvoer

Op het scherm verschijnen twee sprites naast elkaar.

De eerste sprite heeft het eerste aantal beentjes.
De tweede sprite heeft het tweede aantal beentjes.

In de console verschijnt na elke functie-aanroep een boodschap.
