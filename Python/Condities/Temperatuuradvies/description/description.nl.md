## Opdracht
<br>

Laat Python een eenvoudig **temperatuuradvies** geven.

### Gegeven

Je programma leest één gehele temperatuur in.

### Wat moet je doen?

+ Is de temperatuur lager dan `10`? Druk `koud` af.
+ Ligt de temperatuur van `10` tot en met `24`? Druk `aangenaam` af.
+ Is de temperatuur `25` of hoger? Druk `warm` af.

Let goed op de **grenswaarden** `10`, `24` en `25`.

### Verwachte uitvoer

Druk **exact één** van deze woorden af:

+ `koud`
+ `aangenaam`
+ `warm`
