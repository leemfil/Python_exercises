# Dichtst bij 100

Twee spelers hebben elk een score.

Schrijf een programma dat de score van beide spelers vraagt.

Bereken voor iedere speler hoe ver de score van **100** ligt. Gebruik hiervoor:

**(score - 100)²**

Controleer daarna of **speler 1 dichter bij 100 ligt dan speler 2**.

Print het resultaat van de vergelijking. De uitvoer is dus `True` of `False`.
